# Vue

Vite + Vue on Node 24.

## Programs

- [`vue-sandbox/`](vue-sandbox/) — the reference app, port 5174.

## Add a program

Copy `vue-sandbox/` to a new sibling folder, change the `name` in `package.json`, and set a free port in `vite.config.ts` (`strictPort` is on). Add the port to `PORTS.md`, then `pnpm install` and `pnpm dev`.
