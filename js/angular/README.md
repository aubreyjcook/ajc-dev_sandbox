# Angular

Angular on Node 22. `@angular/cli` is a dev dependency of each program.

## Programs

- [`angular-sandbox/`](angular-sandbox/) — the reference app, port 4200.

## Add a program

Copy `angular-sandbox/` to a new sibling folder. Update the project name and `outputPath` in `angular.json`, the `name` in `package.json`, and `mise.toml` if you need a different Node version. Use a free port and add it to `PORTS.md`.
