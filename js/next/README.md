# Next.js

Next.js on Node 24.

## Programs

- [`next-sandbox/`](next-sandbox/) — the reference app, port 3000.

## Add a program

Copy `next-sandbox/` to a new sibling folder, change the `name` in `package.json`, and give it a free port (edit the `--port` flags in `package.json` and add the port to `PORTS.md`). Run `pnpm install` in the new folder before `pnpm dev`.
